# UTA UI Standards Seed

## Visual Identity
UTA uses a premium travel palette:
- Night / plum base
- Passport purple
- Sunset orange
- Gold highlight
- Mint / sky support colors

## Motifs
Use travel-sign language throughout:
- Road signs
- Airport gate cards
- No-wake / boating signs
- Tickets
- Fuel markers
- Passport / vault badges

## Principles
- Information first
- Optional modules remain visible only where useful
- Cards should feel like travel instruments, not default app containers
- Warnings are clear but not preachy
- UTA estimates, it does not instruct unsafe driving
